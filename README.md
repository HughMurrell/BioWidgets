# BioWidgets
various bioinformatics shell scripts and javascript widgets that run in the browesr

**mafftProfileMerge** a shell scripot that profile aligns a list of alignments in fasta format.

**aliViz** a javascript app that allows the user to load an alignment, create a tree, cluster the sequences and generate escape logos at user specified epitopes

**fastaCompliance** a javascript app that allows the user to generate find and replace rules that transform file names and sequence names to satisfy UCT HIVDiversity standard naming conventions.

**fasta2standard.py** a python script that applys fastaCompliance rules to batches of fasta files.
